## Embedded system design
이 repository에는 "임베디드시스템설계"에서 수행한 LAB 중 일부를 담고 있습니다. memory mapped io, polled io, device driver 등을 실습해보며 임베디드 시스템에 대해 전반적인 이해를 쌓았습니다. 개발보드는 **de1-soc board**를 이용하여 진행하였습니다.
